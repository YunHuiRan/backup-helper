# 备份助手（BackupHelper）

带 **Windows 原生图形界面（C# / WinForms，编译成单个 exe，无需安装 .NET SDK 和任何第三方库）** 的文件夹选择性备份工具。

## 一、功能

1. 选择两个文件夹路径：**原文件夹（要备份的文件夹）** 和 **备份文件夹（备份存到哪里）**，界面上每个输入框前面都有对应的中文说明文字。
2. 自动列出**原文件夹中所有子文件夹**（树形显示，可逐级展开到任意深度）。
3. 可以**单独勾选任意子文件夹**（勾选父文件夹时子文件夹自动跟随，"全选 / 全不选"一键操作）。
4. 把选中的子文件夹备份到备份文件夹：
   - 备份文件夹里**已有同名文件夹 → 合并**（按文件逐个合并进去，原有文件不会被删除）；
   - 备份文件夹里**没有同名文件夹 → 新建文件夹**（整份备份，包含其所有深层子文件夹与文件）；
   - 合并时遇到**同名文件 → 自动重命名**新来的文件（`报告.docx` → `报告 (1).docx` → `报告 (2).docx` …），
     两份都保留，绝不会覆盖已有数据。
5. 实时显示进度条、已处理/总文件数，以及逐条操作日志（含"重命名 / 跳过 / 新建文件夹"记录）。
6. 支持取消备份、备份完成后一键"打开备份目录"。
7. 可选项：
   - `同名文件直接覆盖`（默认**不勾选** = 自动重命名保留两份；勾选后同名文件被新文件替换）；
   - `跳过内容完全相同的文件`（默认勾选：同名且内容逐字节相同的文件不再产生副本）。

## 二、运行

```
双击 run.bat
```
或编译后直接双击 `BackupHelper.exe`。

## 三、操作步骤

1. 「原文件夹（要备份的文件夹）」点 **浏览...** 选择源目录（也支持把文件夹直接拖进输入框）；
   选好后会自动列出该目录下的所有一级子文件夹。
2. 「备份文件夹（备份存到哪里）」点 **浏览...** 选择备份目录（目录不存在时会在开始备份前询问是否创建）。
3. 在上方树中**勾选需要备份的子文件夹**，可展开查看更深的层级。
4. 需要时调整「同名文件直接覆盖」「跳过内容完全相同的文件」两个选项。
5. 点 **开始备份**；过程中可点 **取消**。完成后会弹窗显示统计（复制 / 重命名 / 跳过 / 新建文件夹 / 错误 数量）。

## 四、备份规则举例

原文件夹 `D:\Src`，备份文件夹 `E:\Bak`，勾选子文件夹 `D:\Src\照片`：

| 备份文件夹里的情况 | 结果 |
| --- | --- |
| 不存在 `E:\Bak\照片` | 新建 `E:\Bak\照片`，里面文件（含深层子目录）完整复制过来 |
| 已存在 `E:\Bak\照片` | 合并：源文件夹里的文件逐个补进 `E:\Bak\照片`，已有的文件保持不动 |
| 合并时遇到同名文件 `1.jpg` | 自动写成 `E:\Bak\照片\1 (1).jpg`（已存在则 `1 (2).jpg`…），原 `1.jpg` 不动 |
| 勾选的是更深层的 `D:\Src\照片\2024` | 备份到 `E:\Bak\照片\2024`（保持相对原文件夹的目录结构） |
| 备份目录本身在被备份的目录里 | 自动跳过备份目录自身，不会无限递归 |

## 五、文件说明

| 文件 | 说明 |
| --- | --- |
| `BackupHelper.cs` | Windows 原生图形界面（WinForms），程序入口 `Program.Main` |
| `BackupEngine.cs` | 备份核心逻辑：路径映射、合并、同名自动重命名、内容比对、进度回调（与界面解耦） |
| `BackupHelper.exe` | 编译生成的程序（`build.bat` 产物） |
| `build.bat` | 编译主程序 |
| `run.bat` | 启动程序（未编译时自动先编译） |
| `EngineTest.cs` / `test.bat` | 控制台测试：验证合并、重命名、跳过、覆盖、去重、异常与防递归（23 项断言） |
| `UiTest.cs` / `uitest.bat` | 界面逻辑测试（不弹窗）：验证路径输入框的说明文字、子文件夹列举、单独勾选、父子联动、结果收集去重（18 项断言） |

## 六、开发 / 编译 / 测试

使用的编译器是 .NET Framework 自带的 `csc.exe`（C# 5 语法），无需 Visual Studio / dotnet SDK：

```bat
build.bat     :: 编译 BackupHelper.exe
test.bat      :: 编译并运行 EngineTest（备份核心测试）
uitest.bat    :: 编译并运行 UiTest（界面逻辑测试）
```

源码为 UTF-8 编码，编译命令带 `/codepage:65001`，因此中文界面文字在中文/英文 Windows 上都正常。

## 七、注意事项

1. 若源文件正被其他程序独占打开，该文件会记录为"复制失败（错误 +1）"，其余文件继续备份。
2. 无权限访问的子文件夹会被跳过并在日志中说明，不会中断整个备份。
3. 符号链接 / 目录联接点会被跳过，避免循环递归。
4. 路径长度受 Windows 传统 260 字符限制（.NET Framework 默认行为），超长路径的文件会记录错误。
